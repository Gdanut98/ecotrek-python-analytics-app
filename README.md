# EcoTrek Python Analytics App

A graduate Python analytics project that progresses from core Python and exploratory analysis through visualization, sentiment-oriented analysis, and Streamlit application delivery.

## Portfolio story
**Python fundamentals → structured analysis → correlation/sales analytics → visualization → interactive Streamlit delivery → GenAI validation lessons**

## Skills demonstrated
Python • NumPy • Pandas • Matplotlib • Plotly • Streamlit • WordCloud • Correlation • Linear Trendlines • Sentiment Visualization • Interactive Analytics

## Application evidence
The original EcoTrek work includes:
- temperature/sales analytical DataFrames
- Plotly scatter analysis with an OLS trendline
- grouped sentiment visualization
- WordCloud generation
- Streamlit page/layout components
- multiple course notebooks documenting the progression from Python fundamentals to app delivery

## Generative-AI lesson
A related graduate exercise reinforced that prompt specificity materially affected output quality. In the portfolio framing, generative AI is treated as an accelerator that still requires analytical validation rather than a substitute for it.

## Repository structure
- `notebooks/original_coursework/` — five graduate notebooks
- `src/app_original.py` — original Streamlit application source
- `docs/` — provenance, executable evidence, and GenAI validation
- `portfolio/` — interview-ready summary

## Evidence boundary
This is an academic portfolio project. Any course-provided data not clearly redistributable is excluded; the code and notebooks demonstrate the analytical workflow.
