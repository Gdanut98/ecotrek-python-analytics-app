# Interview One-Pager — EcoTrek Python Analytics App

**Problem:** Turn a sequence of Python analytical tasks into an interactive, stakeholder-friendly application.

**Approach:** Build foundational analysis with NumPy/Pandas, explore relationships and sales patterns, create Matplotlib/Plotly visuals, add sentiment-oriented visualizations and WordClouds, and package the work in Streamlit.

**Value:** Demonstrates progression from notebook analysis to lightweight application delivery.

**Technical evidence:** Five notebooks plus original Streamlit source.
